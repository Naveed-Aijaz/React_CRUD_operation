 # 📝 Modern Todo / Post App (CRUD)

A clean and modern **CRUD application** built with React and SCSS featuring a dark SaaS-style UI, smooth interactions, and responsive design.

---

## ✨ Features

- ➕ Create posts / todos
- ✏️ Edit existing items
- ❌ Delete items
- ⏱️ Timestamp using Moment.js
- 🎨 Modern dark UI (glass + SaaS style)
- 📱 Fully responsive design
- ⚡ Smooth hover interactions

---

## 🛠️ Tech Stack

- React.js ⚛️
- SCSS 🎨
- JavaScript (ES6+)
- Moment.js ⏱️
